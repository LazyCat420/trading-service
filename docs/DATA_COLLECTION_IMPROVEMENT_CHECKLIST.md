## What each fix is

1. **`quant_equation_library` — parameters empty — an equation with no parameters cannot be reproduced**  
   Measured: 231 of 232 (99.6%). Fix: Persist parameters when the equation is registered.  
   Location: `app/processors/quant_processor.py`

2. **`news_articles` — qualitative_draft never written**  
   Measured: 88,572 of 89,419 (99.1%). Fix: Same: populate on ingest or remove the column.  
   Location: `app/processors`

3. **`cycle_run_summaries` — collector_failures empty — a cycle that lost collectors looks identical to a clean one**  
   Measured: 344 of 363 (94.8%). Fix: Record every collector failure on the cycle summary.  
   Location: `app/services/cycle_scheduler.py`

4. **`decision_outcomes` — models_used not recorded — a decision cannot be attributed to the model that made it**  
   Measured: 2,361 of 2,618 (90.2%). Fix: Record model provenance on every decision write.  
   Location: `decision outcome writer`

5. **`youtube_transcripts` — quality_status is never assigned**  
   Measured: 8,709 of 9,927 (87.7%). Fix: Score transcripts at ingest like news articles.  
   Location: `app/collectors youtube ingest`

6. **`decision_outcomes` — skill_versions not recorded**  
   Measured: 2,192 of 2,618 (83.7%). Fix: As above.  
   Location: `decision outcome writer`

7. **`news_articles` — quality_status is never assigned — the quality pipeline never ran on these rows**  
   Measured: 32,746 of 89,419 (36.6%). Fix: Backfill the classifier over unscored rows and make scoring part of ingest.  
   Location: `app/collectors news ingest + quality scorer`

8. **`news_articles` — grounded_facts never extracted**  
   Measured: 21,002 of 89,419 (23.5%). Fix: Either run fact extraction on ingest or drop the column from the contract.  
   Location: `app/processors fact extraction`

9. **`fundamentals` — revenue missing**  
   Measured: 1,031 of 9,863 (10.5%). Fix: As above.  
   Location: `app/collectors/fund_scanner.py`

10. **`fundamentals` — both P/E fields missing**  
   Measured: 527 of 9,863 (5.3%). Fix: As above.  
   Location: `app/collectors/fund_scanner.py`

11. **`fundamentals` — market_cap missing — the provider returned a partial record**  
   Measured: 77 of 9,863 (0.8%). Fix: Retry partial fundamentals fetches and record which provider fields were absent instead of writing NULL silently.  
   Location: `app/collectors/fund_scanner.py`

12. **`pipeline_events` — Events are logged with an empty `{}` payload — the step fired but recorded nothing about what it did**  
   Measured: 0 of 189,478 (0.0%). Fix: Make the payload mandatory at the emit site; a step with nothing to say should not emit an event.  
   Location: `app/db/pipeline_state.py, collectors that emit `news_scraped` and `consensus``

13. **`data_archive` — rows sit past the purge_after date the archiver stamped on them — the retention job never ran**  
   Measured: 0 of 13,320 (0.0%). Fix: Schedule the retention sweep, or stop writing purge_after.  
   Location: `archiver / janitor job`

14. **`pipeline_events` — Step names embed the ticker and agent (`v2_debate_UBS_Technical_bull_t`), so every ticker invents new step kinds and no query can group by step**  
   Measured: 11,077 distinct step names (over 189,478 rows). Fix: Emit `step='v2_debate'` with ticker/agent/side as separate fields.  
   Location: `app/v3 debate emitters`

15. **`price_history` — the same (ticker,date) day is carried by more than one source with no documented reader preference**  
   Measured: 34,093 multi-source days (over 15,755,628 rows). Fix: NOT a duplicate defect — the natural key is (ticker,date,source) and it has zero duplicates. Pick a documented source priority for readers and add a UNIQUE index on (ticker,date,source) in Mongo.  
   Location: `app/db/collections.py index spec + price readers`
