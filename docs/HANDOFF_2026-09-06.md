## Two things about how this went

- **Do not put a mutating agent and a reading agent in one worktree.** The
  completeness reviewer reported the branch's own tests as flaky; the failures
  were the refuter's live mutations, in the same tree, at the same moment.
  25 clean re-runs afterwards.
- **A green suite you did not read is not a green suite.** A client run was
  taken as passing on its exit code; the `--timeout` flag it used is not
  installed in that venv, so pytest errored out and a test with a real false
  positive went to `main`. Read the count.
